1. SERDES 在做什么？

改变“每次并行输入多少 bit”，观察它如何变成一串按时间发送的 bit，再在接收端恢复。这里把协议细节抽象掉，只保留物理层的核心动作。

2. GPU 数量增加后，系统一定线性变快吗？

模型假设任务可以并行，但每个 GPU 都要搬运数据。柱子只用于比较相对时间：数值越小越好；实际芯片还会受到 cache、同步、协议、调度和负载不均衡影响。

增加 GPU 后计算柱缩短可并行的计算工作被分摊到更多 SM；这是 throughput 侧的收益。
提高数据复用后通信柱缩短同一份数据被更多计算使用，平均每次计算需要跨互连搬运的字节减少。
互连变慢或 GPU 太多通信成为关键路径；更多计算单元可能在等待数据，不能期待线性加速。

模型性质：这是教学重绘与理想化模拟，不是任何具体 GPU、NVLink、PCIe 或 SERDES PHY 的性能承诺。SERDES 本身是高速物理层技术；PCIe、CXL、NVLink 等还包含更高层的协议、链路管理与软件栈。
